# Komp-Geom examples

Small, focused examples showing how to use [Komp-Geom](https://github.com/cponfick/komp-geom) from different applications and languages.

## Examples

- [`spinning-donut`](spinning-donut/) — a Java terminal animation that builds and rotates a torus with `Vec3` and `AffineTransformationMatrix3`.

Each example is an independent Gradle subproject.
